## Key Decisions

- VectorStore / EmbeddingClient 均用 ABC + abstractmethod，镜像 llm_client/base.py 抽象风格
- add_documents 同步门面 + aadd_documents 异步核心（asyncio.run + Semaphore 分片并发），对外保持同步 API
- 懒创建 collection + 按 embedding.dimension 自动推导维度，错配抛 DimensionMismatchError
- chromadb / openai / sentence-transformers 三者均懒导入，未安装重依赖也能 import vector_store（单测 mock 完全离线）
- 测试三层：mock 单测（离线）+ @integration 真 chromadb（importorskip）+ @slow 性能（1000 条 QPS/召回），假 embedding 放测试侧
- Qdrant 仅提供 docker-compose 起服务（127.0.0.1 绑定），不写 QdrantStore 实现
